LumbungKeluarga — situs anggaran rumah tangga Keluarga Wijaya: dasbor bulanan dengan donat pengeluaran per kategori, anggaran per kategori yang bisa diubah batasnya, transaksi yang bisa ditambah/dihapus, tagihan rutin dengan pengingat jatuh tempo, tujuan tabungan, dan laporan bulanan. Semua berjalan offline dari file statis, di desktop maupun HP, dan data tersimpan di localStorage perangkat.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

Lalu buka `out/app/index.html` di browser, atau sajikan `out/app/` dengan server statis apa pun.
